# SIGRT – Système Intégré de Gestion des Ressources et des Talents

## Structure
- `index.html` : point d'entrée
- `frontend/css/` : styles
- `frontend/js/` : logique de l'interface
- `backend/` : futur backend/API
- `database/` : schémas et migrations
- `modules/` : modules métier
- `docs/` : cahiers des charges et UML

## Lancer le prototype
Ouvrir `index.html` dans Chrome ou Edge.

Identifiants de démonstration :
- utilisateur : `admin`
- mot de passe : `sigrt123`

## Prochaine étape
Développer le module Collaborateurs puis connecter le frontend à un backend et une base de données réelle.
